1. Fundamental Teknologi

Apa itu AIoT? Mari kita bedah satu per satu (tekan panah bawah ⬇️)

Artificial Intelligence (AI)

Otak Digital: Algoritma pemrosesan data, pengenalan pola, dan pengambilan keputusan cerdas secara otonom tanpa campur tangan manusia.

Internet of Things (IoT)

Sistem Saraf & Sensor: Jaringan perangkat fisik (hardware) ber-sensor yang saling terhubung untuk mengumpulkan dan mentransmisikan data real-time.

Konvergensi: AIoT

Penggabungan AI dan IoT. Sensor mengumpulkan data lingkungan, kemudian AI secara langsung (di edge/cloud) menganalisis data tersebut untuk memicu aksi otomatis (actuation).

2. Arsitektur Teknis AIoT

  • Perception (Sensor): MEMS, Camera, ADC, GPIO.
  • Network (Jaringan): MQTT, CoAP, LoRaWAN, Wi-Fi.
  • Edge Processing: TinyML, TFLite Micro pada ESP32 / STM32.
  • Application (Cloud): InfluxDB, Grafana, AWS IoT, Dashboard.

3. Studi Kasus Riset di ITERA

  • Smart Agriculture: Pengering kopi hibrida AIoT, mendeteksi suhu dan kadar air berbasis TinyML.
  • Smart Village Karang Anyar: Monitoring dan kontrol otomatis mikroklimat pada kumbung jamur tiram.
  • Kebun Raya ITERA: Node sensor terdistribusi berbasis LoRaWAN untuk memantau kualitas udara dan kelembaban tanah.

4. Peluang Pendanaan Riset

  • Hibah HIKARI ITERA: Pendanaan internal kampus untuk inovasi karya prototipe hardware & AIoT mahasiswa.
  • PKM Belmawa (PKM-KC/RE): Kompetisi nasional Kemenristekdikti menuju PIMNAS.
  • Kedaireka & Mitras DUDI: Matching grant untuk kolaborasi riset dosen, mahasiswa, dan industri.

5. Potensi Hak Kekayaan Intelektual

  • Hak Cipta: Perlindungan source code (C++/Python), aplikasi mobile, & web dashboard monitoring.
  • Paten / Paten Sederhana: Perlindungan untuk metode algoritma AI, alur inferensi sensor, atau sistem kendali mekanis alat.
  • Desain Industri: Estetika bentuk fisik dan casing enclosure alat (misal hasil 3D printing node sensor).

Roadmap Karir AIoT

  • Embedded ML Engineer: Fokus pada C/C++, Microcontrollers, RTOS, dan optimasi TinyML.
  • AIoT Solutions Architect: Merancang topologi MQTT, Cloud AWS/GCP, dan keamanan jaringan.
  • Edge AI Researcher: Fokus riset kompresi model AI (Quantization/Pruning) dan Computer Vision untuk perangkat low-power.
